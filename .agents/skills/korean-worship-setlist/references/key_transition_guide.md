# 조성(Key) 전조 · 박자/BPM 전환 · 기타 카포 실전 가이드

## 1. Key 전이 선호 순위 및 화성 공식

예배 서사와 템포 방향성을 **1순위 고정 제약**으로 유지한 상태에서 아래 우선순위로 Key 연결을 최적화합니다.

| 순위 | 전이 유형 | 예시 | 음악적/예배적 효과 | 비고 |
| :--- | :--- | :--- | :--- | :--- |
| 1 | **동일 키 유지** | `G → G` | 반주 끊김 없는 메들리(`segue`) 최적 | 가창 안정감 최고 |
| 2 | **온음 상승 (+2)** | `G → A`, `F → G`, `D → E` | 에너지와 예배 기대감을 자연스럽게 상승 | 한국 워십 표준 전조 |
| 3 | **4·5도권 인접 (+5/-5)** | `G → C`, `G → D`, `A → D` | 공통 코드가 많아 부드러운 피벗 연결 | 과도한 긴장 없이 전환 |
| 4 | **나란한조 이동** | `G ↔ Em`, `C ↔ Am` | 선포 → 깊은 고백/묵상 분위기 전환 | 동일 조표 공유 |
| 5 | **반음 상승 (+1)** | `G → Ab`, `C → Db`, `D → Eb` | 클라이맥스 극대화 | `beginner_friendly` 시 주의 |
| **회피** | **증4도 / 원격 조** | `C → F#`, `G → Db` | 공통 코드 부재로 불협화음 발생 | 증4도(6반음) 또는 공통 코드 없는 원격 조 전조 시 반드시 `pad_break` 모드로 전환 |

### 정확한 브릿지 연결 코드 공식
단순히 타겟 키의 `I`만 가정하지 않고 **앞곡 마지막 코드(`outro_last_chord`)** 와 **뒷곡 첫 코드(`intro_first_chord`)** 를 함께 대조해 연결합니다.

1. **도미넌트7 (`V7`) & `V7sus4` (`IV/V` 분수코드)**:
   - 타겟 키의 `V7`을 직접 치거나, 현대 워십에서 부드럽게 많이 쓰는 **`V7sus4` (= 타겟 키의 `IV/V` 분수코드)** 를 거쳐 `V7`으로 해결합니다.
   - 예 (`G Key → A Key`, 타겟 첫 코드 `A`): `G` 끝낸 뒤 → **`D/E` (`V7sus4`) → `E7` (`V7`) → `A`**
   - 예 (`G Key → A Key`, 타겟 첫 코드 `Dmaj7 [IV]`): `D/E` 또는 `E7sus4` 직후 바로 `Dmaj7` 진입은 도미넌트 해결감이 달라지므로 **`A/C#` 또는 `Em7 → A7` (타겟 키의 `V/IV` 세컨더리 도미넌트)** 로 `Dmaj7`에 부드럽게 착지합니다.
   - 예 (타겟 첫 코드 `F#m7 [VIm7]`): **`C#7` (또는 `C#7/E#`) → `F#m7`** 또는 패드 홀드 후 직접 진입.
2. **서브도미넌트 마이너 (`IVm6`) 연결**:
   - 주로 발라드나 온음/반음 전환·종지감 완화 시 타겟 키의 **`IVm6`** (또는 `iiø7`)를 경유합니다.
   - 예 (`A Key` 진입 시): **`Dm6` (`IVm6`) → `A`** (부드러운 서정적 해결).
   - *(주의: `IV/V`는 서브도미넌트 마이너가 아니라 `V7sus4` 보이싱이며, `A/E`는 `I/5` 전위이므로 혼용하지 않습니다.)*

## 2. 박자(`4/4 ↔ 6/8`) · 리듬(Groove) · BPM 낙차 전환 모드

| 모드 | 발생 조건 | 세션 전환 큐(Cue) 출력 |
| :--- | :--- | :--- |
| **`segue` (직결 메들리)** | 동일 박자 AND 리듬 분박 호환(예: 스트레이트↔스트레이트) AND BPM 차이 `< 25` AND 카포 이동 충돌 없음 | `[바로 연결] 마지막 마디 브릿지 코드(예: D/E - E7)로 쉼 없이 진입` *(DB 미검증 추정 빠른 곡끼리는 악보 리듬 일치 확인 주석 병기)* |
| **`rhythm_reset` (리듬 리셋 전환)** | 동일 박자·비슷한 BPM이어도 리듬 분박 충돌(예: **셔플/바운스 ↔ 스트레이트 8·16비트**, **고고/컨트리 ↔ 16비트**) | `[리듬 리셋 전환] 앞곡 정박 엔딩 후 드럼 하이햇/스틱 4박 카운트로 새 리듬 진입` |
| **`pad_break` (패드·멘트 전환)** | 박자 변경(`4/4 ↔ 6/8·3/4`) OR BPM 차이 `>= 25` OR 증4도 전조 OR 카포 이동 필요 | `[패드 홀드] 건반 패드 유지 + 인도자 멘트/기도 후 드럼/카운트로 6/8 박자 리셋` |

- 빠른 곡(125 BPM)에서 느린 곡(62~68 BPM)으로 절반 가까이 떨어질 때, 박자 맥락이 맞으면 **`[Half-time 클릭/패드 전환]`** 팁을 함께 제공합니다.

## 3. 기타 카포(Capo) 매핑 & 세션 숙련도 가이드

`session_skill_tier == "beginner_friendly"`일 때는 임시표 4~5개 Key(`Ab`, `Db`, `Gb`, `B`)의 생연주를 피하거나 어쿠스틱 기타 카포 오픈코드 폼을 자동 제시합니다.

| 실연 Key | 권장 기타 카포 폼 | 연속 `segue` 곡 주의사항 |
| :--- | :--- | :--- |
| `Ab` | **Capo 1 (G 폼)** | 이전 곡이 `G(No Capo)`면 `segue` 중 1프렛 장착 불가 → `pad_break` 권고 |
| `Bb` | **Capo 3 (G 폼)** 또는 **Capo 1 (A 폼)** | 다음 곡 `C`면 Capo 3 해제 시간 확보 |
| `Db` | **Capo 1 (C 폼)** | - |
| `Eb` | **Capo 1 (D 폼)** 또는 **Capo 3 (C 폼)** | `D → Eb` 반음 상승 시 1프렛 이동보다 `pad_break` 권장 |
| `F` | **Capo 3 (D 폼)** 또는 **Capo 5 (C 폼)** | 바레코드 부담 시 사용 |
| `B` | **Capo 2 (A 폼)** 또는 **Capo 4 (G 폼)** | - |
